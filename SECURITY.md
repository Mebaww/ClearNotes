# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in ClearNotes, please do not open a public issue.

Instead, please report vulnerabilities by contacting the maintainers directly via email or opening a private security advisory on GitHub if enabled.

When reporting, please include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue or a proof-of-concept.
- Potential impact and suggested mitigations if known.

We will acknowledge receipt of your report within 48 hours and work with you to address the vulnerability before public disclosure.
